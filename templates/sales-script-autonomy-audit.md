## Autonomy reconstruction

- Neutral current-state question:
- Tentative summary with invitation to correct:
- Reasonable options, including no change, self-service, competitor and referral:
- Evidence, price, effort, uncertainty, material risks and non-fit:
- Reflection/asynchronous path:
- Easy refusal and finality:
- What—if anything—the recipient chooses next:

## Claim gates

| Claim class | Evidence and review required | Status |
| --- | --- | --- |
| Health/product | Product, population, magnitude, timeframe, risks/interactions, regulation and referral | |
| Earnings/opportunity | Representative gross/net outcomes, denominator, costs, time, attrition and recruitment dependence | |
| Testimonial/case | Consent, selection, typicality, attribution, scope and currentness | |
| Platform/performance | Source, method, date, baseline and current verification | |
