# Sources

Immutable evidence archive. Existing category folders are preserved because moving them into the new taxonomy without document-level provenance review would create false classifications and break trace links.

## Target taxonomy

- `primary/`: direct records, original data, approved first-party documents.
- `scientific/`: papers, reviews, guidelines, and scientific evidence packages.
- `books/`: book notes and licensed excerpts/metadata.
- `internal/`: internal strategy, assessments, plans, and operating documents.
- `transcripts/`: interview, podcast, video, and session transcripts with permissions.
- `external/`: third-party market, competitor, media, and vendor material.

## Migration rule

Classify one file at a time, preserve the original filename, update every repository link, and record whether it is primary or derived. Do not duplicate a source merely to satisfy taxonomy.

Current inventory and duplicate notes: [source register](../SOURCES.md).

Folder-by-folder ingestion coverage and the active expansion queue: [research/source-maps](../research/source-maps/README.md).

## Source versus derived knowledge

Original paper, transcript, strategy, analytics export, or workbook belongs here. Synthesis belongs in `research/` or `knowledge/`. Vlad’s interpretation belongs in `frameworks/`. Application belongs in `projects/`. Public expression belongs in `content/`.
