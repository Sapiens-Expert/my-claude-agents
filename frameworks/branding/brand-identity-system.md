# Brand identity system

Use this framework to define and govern durable brand meaning after the business strategy, brand role and evidence frame are clear.

## 1. Contract the identity decision

Define the brand, portfolio role, owner, horizon, audiences, strategic challenge and implementation authority. State what this work will change and what remains outside scope.

## 2. Establish current image

Collect unaided/aided perception, retrieval, language, associations, reputation, distinctive-asset and experience evidence. Separate buyers/nonbuyers and direct evidence/internal belief.

## 3. Define the core identity

Select the smallest set of durable meanings required by strategy. For each, specify audience value, organizational commitment, capability, proof, decision consequence and disconfirming evidence.

## 4. Add only useful extended identity

Use product/service, organization, person and symbol perspectives to make the core concrete. Retain an element only if it improves value, behavior, recognition or decision coherence.

## 5. Set boundaries and relationship

Define scope, non-fit, prohibited associations, nonclaims, brand-separation triggers and cross-domain authority limits. Specify the observable relationship stance and recovery behavior.

## 6. Select the active position

Choose the relevant subset of identity to communicate for the current strategic challenge. Use the [positioning framework](positioning-design.md); do not reduce identity to a tagline.

## 7. Align execution

Translate core elements into product, offer, experience, price, access, proof, vocabulary, assets, content, sales, service, partnerships, people and incentives. Assign owners and resolve contradictions.

## 8. Measure and govern

Build a decision-specific dashboard spanning image, retrieval, asset attribution, experience, behavior and outcomes. Separate size/user effects and avoid false composite precision. Set review and change triggers.

## Output contract

Produce a [brand identity brief](../../templates/brand-identity-brief.md), execution map, evidence links, ownership, prohibited uses and decision record.
