# Customer-centered message

Use after strategy, audience evidence, offer validation and claim review. It is optional when another structure better fits the decision.

## 1. Contract the decision

Define buyer, user and other stakeholders; situation; desired progress; current alternative; message job; channel; and legitimate next action.

## 2. Validate the problem

Record observable problem and direct audience language. Separate external barrier, reported internal experience and any ethical meaning. Remove inferred shame, diagnosis, villain and invented injustice.

## 3. Bound the brand role

Choose resource, provider, specialist, facilitator or guide. State relevant capability, qualifications, proof, empathy-in-conduct, conflicts, limitations and non-fit. Prevent cross-domain authority transfer.

## 4. Specify the real plan

State steps, prerequisites, participant/provider responsibilities, time, effort, price/cost, uncertainty, risks, safety gates and referral/stop conditions.

## 5. Choose proportionate actions

Define one direct and one genuinely useful transitional action where appropriate. Make consent, data use, reversibility and refusal clear.

## 6. Calibrate stakes and outcomes

Describe action, no-action and alternatives using base rates and uncertainty. Define observable success, time horizon and variability. Transformation language is optional and evidence gated.

## 7. Build the layered message

Use the evidence-preserving message framework to create core, concrete explanation, evidence, boundary and action. Retain category cues and distinctive attribution.

## 8. Test and govern

Test comprehension, intended/unintended interpretation, authority perception, qualified response, outcome, complaint and harm. Compare against a non-narrative message. Version and revise by evidence.

## Output contract

Complete the [customer-centered message brief](../../templates/customer-centered-message-brief.md), with linked audience evidence, claims and channel-specific test.
