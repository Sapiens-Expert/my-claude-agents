# SapiensOS overview

SapiensOS is a ten-domain framework for translating healthspan knowledge into daily behavior: sleep, nutrition, movement, stress, social connection, light/dark rhythms, agency, meaning, rest, and curiosity.

The domains are interdependent. The framework should prioritize the limiting constraint rather than ask users to optimize all ten simultaneously.

## Curriculum organization

- Foundations: sleep, nutrition, and movement.
- Regulation/context: stress, social connection, light/dark rhythms, and agency.
- Coherence: meaning, rest, and curiosity.

This three-part organization is a teaching scaffold, not evidence that every person should progress linearly or that each domain has equal causal weight. The curriculum archive contains useful lessons and exercises but requires claim-level scientific, clinical-scope, accessibility, and outcome review before republication.
