# Epistemic classes

| Class | Meaning | Typical location |
| --- | --- | --- |
| FACT | Verifiably true about Vlad, a brand, project, or business | `identity/`, `state/`, project records |
| PRINCIPLE | Durable belief or decision rule | `voice/`, `frameworks/`, governance |
| EVIDENCE | Research supporting or challenging a proposition | `research/`, `sources/` |
| STRATEGY | Chosen approach for an objective | `projects/`, `platforms/`, `sops/` |
| DECISION | Time-specific choice with rationale and supersession | `decisions/` |
| HYPOTHESIS | Plausible but not established | `research/claim-register.md`, experiments |

Each canonical file declares one primary class in frontmatter. A document may contain supporting facts or hypotheses, but its primary authority must remain clear.
