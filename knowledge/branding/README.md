# Branding

Brand strategy connects business strategy, customer/category understanding, identity, memory, experience, architecture, and measurement. Canonical choices for a specific brand live in `brands/`; this folder contains reusable knowledge.

## Core distinctions

| Concept | Meaning |
| --- | --- |
| Brand image | Associations people currently hold |
| Brand identity/vision | Associations the organization intends to create and sustain |
| Positioning | The relevant frame, audience, benefit/meaning, and reason to believe the brand seeks to own |
| Differentiation | Meaningful reasons to choose or perceive the brand differently |
| Distinctive assets | Recognizable non-name cues that build memory and identification |
| Mental availability | Probability the brand comes to mind in relevant buying situations |
| Physical availability | Ease of finding, accessing, and buying the brand |
| Brand equity | Brand-linked assets/liabilities that affect customer and business value |
| Brand architecture | Roles and relationships among corporate, master, endorsed, sub-, and product brands |
| Category relevance | Whether the brand is considered when a customer defines the category/subcategory need |

## Strategic tensions

- Focus can create meaning and operating advantage; excessive narrowing can reduce reach or future options.
- Differentiation supports choice; distinctiveness and availability support memory and growth.
- Category creation can change the comparison set; it requires a real innovation, decision criterion, or use case—not naming alone.
- Extensions can create leverage or destroy clarity depending on fit, credibility, architecture, and execution.
- Consistency compounds memory; adaptation preserves relevance.
- Purpose may strengthen culture, differentiation, and relationships only when embedded in behavior and measurable impact.
- Cultural stories can create identity value but cannot be engineered from stereotypes or borrowed legitimacy.
