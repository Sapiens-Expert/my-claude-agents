# Strategy knowledge

Strategy is a reasoned set of choices for overcoming a consequential challenge. It connects diagnosis to a guiding approach and a coherent system of action, while making assumptions, trade-offs, evidence and learning explicit.

## Governing distinction

Vision describes a desired future. Goals specify outcomes. Plans organize activity. Strategy explains what makes progress difficult, which approach will address it, and why a coordinated set of actions should work.

Source-specific models remain in `research/deep-extraction/books/`. Canonical knowledge includes only concepts that survive comparison across strategy, positioning, category, branding, product and empirical growth sources.
