# Start here

VladOS separates stable identity, live state, public expression, knowledge, execution, and evidence so they do not overwrite one another.

## Required reading order

1. [Current state](state/NOW.md)
2. [Profile](PROFILE.md)
3. [AI governance](AI-GOVERNANCE.md) when using an assistant
4. [Knowledge index](INDEX.md)
5. Relevant active decision, brand, voice, framework, project, and research files
6. Original sources for consequential claims

## Where information belongs

- Stable facts about Vlad → `identity/`
- Changing priorities and constraints → `state/`
- Public positioning and boundaries → `brands/`
- Tone, reasoning, and evidence language → `voice/`
- Proprietary models → `frameworks/`
- Evergreen subject matter → `knowledge/`
- Outcomes, milestones, and metrics → `projects/`
- Channel-specific rules → `platforms/`
- Evidence and open claims → `research/`
- Working/published material → `content/`
- Media and deliverables → `assets/`
- Repeatable procedures → `sops/`
- Material choices → `decisions/`
- Originals → `sources/`

## Maintenance rule

Update an existing canonical file instead of creating another master plan. Mark unknown, contradictory, stale, or inferred information explicitly. Preserve source files and trace material conclusions back to them.

## Core AI rules

- Never combine brand contexts automatically.
- Distinguish strong, moderate, emerging, observational, and hypothetical evidence.
- Current active decisions override historical strategies.
- If metadata cannot resolve a conflict, report it.
- Mechanism first; evidence calibrated; expert peer, not guru.
- No manipulative persuasion, motivational endings, or em dashes in public copy.
- Optimize for trust, qualified conversations, clients, referrals, intellectual authority, and long-term brand equity, not reach for its own sake.
