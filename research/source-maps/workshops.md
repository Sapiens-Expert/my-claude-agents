# Workshops source map

## Processing model

Twenty-seven PDFs were mapped. The seven short framework documents were read as complete comparative references; the twenty books were treated as bounded libraries through metadata, contents, and relevant design concepts. No exact duplicates occur in this folder.

The framework PDFs appear to document named third-party/provider approaches. Their presence does not make them Vlad-owned intellectual property, authorize resale, or establish that Vlad delivered them.

## Internal framework/reference set

| Source | Reusable pattern and limit |
| --- | --- |
| `Frameworks/Framework Beyond Taylor.pdf` | Customer pains → values → strategy canvas/USP → value leaders → authority/resources → metrics/cadence; “Beyond Taylor” attribution and ownership require clarification |
| `Frameworks/Framework One Story.pdf` | Disrupt-model exploration using pre-research, shared context, World Café-style ideation, selection, and action planning; reference design, not validated innovation method |
| `Frameworks/Framework The Edgers.pdf` | Two-day Forming → Storming → Dreaming → Performing growth/experiment sequence; provider framework and context-dependent group-development metaphor |
| `Frameworks/Framework Ward Howell.pdf` | Teaming session covering outcomes, barriers, supergoal, competencies, interaction rules/formats, leader model, and actions; attributed reference |
| `Frameworks/Framework strategy partners.pdf` | Crisis digitalization: business models → threats → required change → enabling technology → transformation governance; provider reference |
| `Frameworks/Framework Экопси.pdf` | Mission/vision design through rationale, market image, stakeholders, core/focus, and formulation; attributed Russian-language reference |
| `Frameworks/Framework ЯиП.pdf` | Crisis 4R pattern: Recognize, React, Resilience, Recovery; contains incomplete timings and generic examples, so use only as a design prompt |
