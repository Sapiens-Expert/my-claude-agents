## Bottom line

Copyediting is controlled editorial judgment, not automated correction. The workbook trains file preparation, markup, queries, style sheets, reference research, punctuation, spelling, names, numbers, quotations, tables/art, citations, front/back matter, grammar, plain/bias-free language and scope control. Its answer keys model reasoning, not merely right answers.

## Governed copyedit workflow

1. Agree audience, variant, style authority, edit level, deliverables and do-not-touch elements.
2. Preserve original/version; run mechanical cleanup transparently.
3. Build a style sheet for spelling, capitalization, numerals, names, terminology, citations and decisions.
4. Edit consistency, grammar, usage, clarity and factual red flags within scope.
5. Query ambiguity, missing evidence, permissions, bias and authorial intent concisely; do not silently rewrite meaning.
6. Check tables/figures against text, units, totals, labels and sources.
7. Check quotations/citations/reference correspondence and rights.
8. Run bias/plain-language/accessibility review with domain context.
9. Deliver clean/marked versions, style sheet, unresolved queries and transmittal memo.
