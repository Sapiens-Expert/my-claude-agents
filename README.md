# VladOS

Vlad’s private, version-controlled operating and knowledge system: identity, brands, voice, frameworks, projects, research, content, procedures, decisions, evidence, and current state.

Start with [START-HERE.md](START-HERE.md).

## Core rules

- `state/` describes what is true and important now.
- `identity/` contains stable facts; `brands/` and `voice/` govern public expression.
- `frameworks/` contains proprietary models; `knowledge/` contains evergreen topic synthesis.
- `projects/` contains execution; `decisions/active/` governs material choices.
- `research/` tracks evidence and claims; `sources/` preserves originals.
- Never infer execution from a polished plan.
- Never commit secrets or inadequately protected client/health data.

AI behavior is governed by [AI-GOVERNANCE.md](AI-GOVERNANCE.md).
