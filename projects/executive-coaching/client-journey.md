# Client journey

Relevant content/referral → conversation → fit call → payment/intake → diagnostic session → protocol within the promised window → bridge decision → Performance Reset → outcome review → referral/testimonial request with consent.

Delivery follows the [coaching-session SOP](../../sops/coaching/coaching-session.md). A written protocol is a collaboratively tested plan, not a prescription. Maintain engagement and client ownership before advancing to action; review outcomes and adverse effects rather than counting sessions or completed tasks alone.
