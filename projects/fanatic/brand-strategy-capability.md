# FANATIC brand-strategy capability

## Capability stack

- Market, category, customer, competitor, and cultural diagnosis.
- Positioning, value proposition, category/subcategory, and strategic focus.
- Brand identity/vision, distinctive assets, memory, and availability.
- Portfolio/architecture, extensions, endorsement, and investment roles.
- Purpose, culture, customer experience, signature stories, and reputation.
- Equity measurement, implementation governance, and learning.

## Productization path

1. Use the canonical diagnostic on one bounded pilot.
2. Define required inputs, decision gates, outputs, quality criteria, and reviewer role.
3. Record source evidence, alternatives, rejected choices, assumptions, and implementation ownership.
4. Observe client decisions and downstream execution—not presentation approval alone.
5. Convert repeated, effective elements into reusable tools while preserving contextual judgment.

The library strengthens conceptual coverage. It does not establish that FANATIC has delivered every capability or achieved client outcomes. Those require project evidence.
