# LinkedIn

Primary O!Sapiens acquisition platform. The operating objective is qualified executive-healthspan relationships, not reach in isolation.

## System

1. **Positioning:** own a precise problem/category association for a defined executive audience.
2. **Profile:** convert relevant attention into recognition, trust, evidence, and a low-friction next step.
3. **Content:** demonstrate mechanisms, judgment, experience, and boundaries.
4. **Comments:** contribute to ICP-adjacent conversations and build repeated familiarity.
5. **Network:** prioritize relevant people and relationships over connection volume.
6. **DMs:** continue genuine context into a useful conversation; move off-platform only with mutual relevance.
7. **Sales Navigator:** create small, actionable account lists from role, company, relationship, and change signals.
8. **Funnel:** profile/post/comment/referral → conversation → fit call → paid diagnostic → bridge → Performance Reset.
9. **Measurement:** attribute qualified conversations and commercial movement while monitoring the attention signals that precede them.

## Freshness rule

LinkedIn interface labels, feature access, search filters, limits, algorithms, and format performance change frequently. Recheck them in the live product or current official documentation before operational use. Books and guides support principles, not current platform truth.
